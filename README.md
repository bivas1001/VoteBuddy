# 🗳️ VoteBuddy AI

**VoteBuddy AI** is an interactive, unbiased, and incredibly user-friendly Election Guide AI assistant. Designed specifically to demystify the electoral process for first-time voters, citizens who have moved, and anyone looking for clear, non-partisan voting information. 

By prioritizing simplicity and an engaging user experience, VoteBuddy replaces long, boring government texts with an interactive, conversational journey.

## 🌟 Why VoteBuddy Stands Out (Judging Criteria Addressed)

1. **Absolute Neutrality:** Built strictly for educational purposes. It offers zero political opinions and only presents facts about the voting process.
2. **Beginner-Friendly Focus:** Specifically engineered for first-time voters with intuitive guides and zero jargon.
3. **High Interactivity:** Moves away from reading "long paragraphs" to a dynamic conversational format with follow-up chips.
4. **Inclusive Accessibility:** Built with ARIA standards, integrated Text-to-Speech (TTS), and specific guides for Persons with Disabilities (PwD).

## 🔥 Key Features

### 1. 🚀 Personalized Voter Journey
Users can select "Personalized Journey" to answer a few quick questions (e.g., "Are you a first-time voter?"). The AI then generates a custom, actionable step-by-step plan rather than generic information.

### 2. 🌍 Multilingual Support
Important for regional accessibility. Users can instantly switch between **English** and **Bengali** with the click of a button, making the information accessible to a broader audience.

### 3. 🧒 ELI10 Mode (Explain Like I'm 10)
For maximum simplicity, users can toggle "ELI10" mode. This converts standard democratic explanations into super simple analogies (e.g., *Voting is like choosing the captain of your class!*).

### 4. ✅ Smart Progress Checklist
A dynamic checklist modal allows users to track their election readiness—from registering online to verifying their name on the electoral roll.

### 5. 🎯 Interactive Readiness Quiz
A built-in 4-question quiz tests the user's readiness and knowledge about the election rules, rewarding them with an interactive score and feedback.

### 6. 🔍 Myth vs Fact Engine
Actively dispels common confusions (e.g., *Myth: Voting costs money. Fact: Voting is completely free!*) using visually distinct UI cards to ensure clarity.

### 7. 📊 Text-Based Visual Timelines
Breaks down the election into a simple "Before / During / After" flow to prevent users from getting overwhelmed by complex election schedules.

### 8. 🔊 Integrated Voice Assistant (Text-to-Speech)
To support users who cannot read well or prefer audio, VoteBuddy features a native **Read Aloud** button on every response, powered by the Web Speech API.

### 9. 🗺️ Location & State-Specific Guidance
Users can ask how to find their specific polling booth, and VoteBuddy provides direct methods (Portals, Apps, SMS) and explains the role of state CEO websites.

### 10. 🛡️ Robust Scenario Handling & Edge Cases
If a user is confused or types a generic greeting, VoteBuddy warmly guides them back. It also handles specific edge cases like:
- *"I lost my voter ID"*
- *"I moved to a new city"*
- *"Information for disabled voters (PwD)"*
- *"Can NRIs vote?"*

## 🛠️ Technology Stack

- **HTML5:** Semantic and accessible structure.
- **CSS3 (Vanilla):** Stunning, responsive glassmorphism UI, custom variables, floating particle animations, and zero heavy frameworks.
- **JavaScript (Vanilla):** Lightweight, zero-dependency state management, DOM manipulation, custom i18n (internationalization), and robust string matching logic.

## 🚀 How to Run Locally

Because VoteBuddy AI is built with pure Vanilla Web Technologies, there are no complex dependencies or build steps required!

1. Clone or download this repository.
2. Open the folder.
3. Double-click on `index.html` to open it in your default web browser.
4. Enjoy interacting with VoteBuddy!
